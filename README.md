# Trae 每日签到

> 一键自动完成 Trae 每日自动签到领积分与积分查询，自动提取本机客户端凭证，支持定时任务无人值守，结果在命令行打印，可在不忙脚本盒子中定时无人值守运行。

---

## 核心特性

- **全自动提取**：自动读取本机已登录的 Trae 客户端凭据与设备密钥，免抓包、免手动填 token
- **一键签到**：打开即签到，无需任何配置；账号凭证提取与签到一次完成
- **Token 自动续期**：refreshToken 轮换自动回写，长期不用手动换
- **解 9074 限流**：命中「参与用户太多」时在本机真实设备号之间自动切换重签
- **当日去重**：当天已签成功的账号不再请求，重复触发也不浪费额度
- **积分查询**：只读查询积分「已用 / 剩余」，绝不触发签到
- **命令行反馈**：签到 / 积分结果直接在命令行打印，实时进度一目了然
- **定时无人值守**：交给不忙脚本盒子定时任务，每天自动跑并回传结果
- **图形化启动**：由盒子渲染启动窗口，选动作、点执行即可

## 安装方法

本脚本的运行环境、依赖组件及图形化窗口均依赖「不忙脚本盒子」，建议仅通过盒子安装和使用本脚本。

> 前置条件：安装好 [不忙脚本盒子](https://www.bm-box.cn)

* 打开盒子 → **脚本市场** → 搜索 **「Trae 每日签到」**
* 点击「安装」

---

## 使用方式

> 前置：本机已登录 Trae 客户端（脚本会自动读取其登录凭据）。

### 方式一：卡片运行（图形化窗口）

* 在盒子里点击脚本卡片
* 选择「执行动作」（每日签到 / 积分查询）
* 点击「执行」，等待完成，结果在命令行打印（结束后 5 秒倒计时自动关闭）

### 方式二：定时任务

* 在盒子里为脚本创建定时任务（如每天 00:23）
* 保持默认动作即可，之后每天自动运行
* 签到汇总结果会回传给盒子记录（无人值守，不弹窗）

## 💡 使用提示

| 参数 | 说明 |
| :--- | :--- |
| **执行动作** | `每日签到` 正常签到；`积分查询` 只读查积分，不签到 |
| **登录文件路径** | 一般留空，自动探测本机 Trae 客户端；探测不到时可手动指定 `storage.json` 路径 |

> 请勿在多处同时刷新同一账号，否则 refreshToken 会互相顶失效。
> 设备号优先使用客户端真实注册号；本机读不到时才会退回生成号（可能被服务端拒成 9074）。
> 手动运行时，命令行执行完毕会 5 秒倒计时后自动关闭，方便查看结果。
